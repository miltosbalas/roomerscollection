ROOMERS COLLECTION - ready-to-upload website (no Node / no build needed)

WORKS 3 WAYS
  1. Double-click index.html on your computer (links look like index.html#/collection)
  2. GitHub Pages, any address (also username.github.io/reponame)
  3. Your own domain with clean URLs: roomerscollection.com/gracevillamykonos

UPLOAD TO GITHUB
  Upload EVERYTHING inside this folder to the repo root (index.html, 404.html,
  CNAME, .nojekyll, assets/ and all the page folders).
  Settings -> Pages -> Deploy from branch -> main / (root)
  Settings -> Pages -> Custom domain: roomerscollection.com (+ Enforce HTTPS)
  DNS A records: 185.199.108.153 / .109.153 / .110.153 / .111.153
  (If you only use username.github.io/reponame, delete the CNAME file.)
